# Villagers+ — Minecraft Bedrock Add-on

## Versão 2.0

### Novas profissões
Pescador, Pastor, Armeiro, Açougueiro e Curtidor, além das profissões da V1.

### Nomes personalizados
Com uma bússola, escolha Personalizar nome e selecione um aldeão Villagers+ próximo.

### Sistema de níveis
Novato 0 XP; Aprendiz 10 XP; Oficial 30 XP; Especialista 60 XP; Mestre 100 XP.

### Trocas
O menu de trocas identifica a profissão, mostra os recursos associados e concede XP de progressão.

### HTML
index.html é a documentação/preview do projeto. HTML não é executado diretamente pelo Minecraft Bedrock.

### Instalação
Ative o Behavior Pack e o Resource Pack no mundo Bedrock.

### Compatibilidade
A API de scripts do Bedrock varia entre versões. Se necessário, ajuste as versões de @minecraft/server no manifest.
