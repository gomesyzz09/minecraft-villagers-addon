# Villagers+ V2

Bússola: abre o menu principal.

Níveis: Novato 0 XP, Aprendiz 10 XP, Oficial 30 XP, Especialista 60 XP, Mestre 100 XP.

Nomes: personalize o aldeão Villagers+ mais próximo.

Trocas: o menu identifica a profissão, mostra recursos associados e adiciona 10 XP por troca.

A V2 adiciona Pescador, Pastor, Armeiro, Açougueiro e Curtidor.
